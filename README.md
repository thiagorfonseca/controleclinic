# Documentação da API do Controle Clinic

Site em Mintlify, publicado em https://controle-clinic.mintlify.site.

## Ver localmente

```bash
npm i -g mint
mint dev        # http://localhost:3000
mint validate   # confere docs.json e o OpenAPI
```

## Publicar

Push na `main` publica sozinho. A aba **Referência da API** vem de
`https://api.controleclinic.com.br/v1/openapi.json`: depois de mudar a API no sistema, clique em
**Manual update** no painel do Mintlify.
